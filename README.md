![Bivie](assets/bivie.png)

Bivie sizes vision-language model serving from a folder of your real files: it counts the exact encoder and token work each file creates, then recommends a topology (aggregated, prefill/decode split, or a separate encoder tier), GPUs per tier, and cost per 1,000 files with P10-P90 ranges. It builds on NVIDIA AIConfigurator for prefill, decode, and encoder estimates, emits deploy configs, and ships `bivie-replay`, a Go load generator that replays your files against a live server and checks every token count. Run `make setup`, `make profile FILES=your/folder`, `make size`, then `make export replay` and point `bin/bivie-replay` at your endpoint with `BASE_URL`. This release is uncalibrated; the calibrated version ships next.
